# Black-Hole-Evaporation
Modeling Hawking radiation and black hole evaporation, from physics to an interactive simulator

An independent research project modeling how black holes lose mass through Hawking radiation, built from first-principles derivations in Python.

## Goal
Calculate how long black holes of any mass take to evaporate, validate the results against published values, and visualize the process in a live simulation.

## Status
In progress: setting up and learning the physics.
